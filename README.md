# Analise de dados relacionados a monitoria de introdução ao calculo

## Decisões tomadas
* Notas "Zero" substituídas por 0
* Notas com p1 e p2 substituídas pela média

* Notas com mais de uma opcao escolhida a menor

## Como rodar
Necessário ter o Python instalado, o dataset Avaliação.csv e as bibliotecas pandas, numpy e matplotlib.
